## 3. The five things that need a person

1. **Sitoo sandbox check.** Does `PUT /products/{id}` patch or replace, and does
   it accept `barcode: null`? If it replaces, the writer would blank every other
   field on the products it touches. One product settles it, and it gates every
   outward write.

2. **The Barnes/Hayes scan.** `7072536087*` is claimed by Hayes in the CFO list
   and by Barnes in Sitoo. The 11 affected variants are locked in the database
   so neither writer can assert them. Only scanning a garment settles it.

3. **The backfill scope.** 4,583 SKUs, of which some are `VN-ONLN` vintage.
   Assumption: everything stocked and sellable comes in, but vintage may belong
   to the vintage module instead.

4. **The Keri question.** `LIV-KRI-DWN` was stated to be correct, but Pio — the
   warehouse — holds `LIV-KR-JPN-DWN`, as do Cin7, Sitoo and Origio. Only
   Shopify uses `KRI`. Either `KRI` is the convention going forward, in which
   case nothing currently holds the right SKU, or Shopify's record is right and
   four systems need changing.

5. **`LIV-Needle-W` vs `LIV-NEEDLE-W`.** Differ only in case. The barcoded side
   is the mixed-case one, so "keep the barcodes" and "keep the right spelling"
   point opposite ways.

## 4. What the work actually established

**Seven wrong conclusions in the earlier reconciliation all came from a missing
qualifier, not from bad data** — identity, lifecycle, product kind, canonical
form. Those distinctions now live in the model, so the next person to query the
master does not repeat them.

**Running the code found what reading it could not.** The imperfect-bucket rule
had never once fired, in this code or the original Python, because patterns were
matched against SKU and name concatenated and the `$` anchor could never hit.
Fixing it moved `NON_PRODUCT` from 106 to 170 and removed 16 rows from the import
allowlist that would have been imported as products.

**Previewing found two hazards worth the whole exercise.** The Sitoo plan wanted
45 writes; 16 should never have been in it. Eleven were the disputed Barnes/Hayes
block, which it would have applied cleanly as a rotation. Five would have
replaced a shop-printed label that scans at the till with a manufacturer EAN that
does not.

**The measurement changed the design, twice.** Fuzzy SKU matching flagged 17,277
false pairs across a corpus with no duplicates, so it was removed rather than
tuned. And no abbreviation rule fits the catalogue — dropping vowels matches 61%
of style names, first-three-letters 27% — so the builder reuses the token a style
already uses instead of deriving a third convention.
