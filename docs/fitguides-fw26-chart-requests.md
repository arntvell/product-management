# FW26 measurement charts — what we need from you

**To:** design / product development
**From:** Origio (product master)
**Date:** 2026-09-16

## Why

The fit guide on livid.no is now generated directly from the FW26 measurement
chart in ThreadFlow. Change the chart and the web page changes with it — nobody
retypes numbers, and the size table a customer reads can no longer drift from
the spec the factory works to.

That is live for **58 of the 69 FW26 styles**. The **11 below are not**, and each
needs something only you can give us.

**Every FW26 style has a chart, and none of these is wrong** — the values that
are there look right. In all 11 cases the problem is the same one.

## The problem: grading increment is 0

The base-size value is entered. The **grading increment** is not — it is 0, so
the chart returns the *same number at every size*. An XS and an XL read
identically, which we cannot put on the site, and we will not invent the grading
ourselves.

**The fix:** the style's FW26 chart → *Manage Measurements & Sizes* → set the
grading increment on the rows listed. Nothing else needs touching.

Where the same style is graded in another season, that increment is shown as a
starting point. **Please confirm it still applies to FW26** — we have seen specs
change between seasons, so treat it as a prompt, not an answer.

## What the website takes from a chart

Only these rows. Everything else is production detail and never reaches a
customer, so a fix only helps if it lands on these.

| Tops | Bottoms |
|---|---|
| Shoulder (across) — *omitted on raglans, which have no shoulder seam* | ½ Waist |
| ½ Width (pit to pit) | ½ Thigh |
| ½ Bottom Width *(or ½ Hem)* | ½ Knee (35 cm) |
| Front Length (from HPS) | ½ Leg Opening |
| | Front Rise (without waistband) |
| | Back Rise (without waistband) |

## Not requests — just so you know

**Five FW26 styles are not approved for production** and are outside this list
until they are: Beth Cord, Barnes Work Suit Trouser, Nox (`LIV-M-NX-001`),
Burley, and `Polo Coat (comment testing)` — the last looks like a test record
someone could delete.

**SS26's charts have the same increment-0 problem almost everywhere** — 54 of 63.
It has not mattered until now because those pages were typed by hand, but it
does mean two live SS26 fit guides are wrong today and cannot be rebuilt from
the chart: **Brass Tee** and **Pen** each publish a chest measurement roughly
12–16cm under the spec. Grading those two SS26 charts fixes both pages
automatically.

## When it is done

Nothing to send back — just say it is in. We read the charts straight from
ThreadFlow and the pages rebuild from whatever is there.
